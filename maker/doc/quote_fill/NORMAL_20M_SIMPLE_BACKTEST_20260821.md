# 2,000 萬上限：最簡 Normal carry 回測

更新日：2026-08-21

## 本圖採用的策略

- Portfolio 同時未平倉上限：20,000,000 TWD，依現貨進場 one-way notional 計算。
- 單一商品上限：6,000,000 TWD（portfolio cap 的 30%）。
- 13:00 起停止開新倉；既有部位仍依原 normal maker exit 出場。
- 不使用 13:00 後貼期貨 B1／現貨 A1 的積極硬出。
- D 日有 opening carry 的商品，D 日整天只出不進。
- 截至 13:20 study cutoff 尚未完成的部位由模型完整帶入下一個交易日；最晚到期以現貨
  與期貨官方 daily Close 同時作會計結清。

正式情境為 `normal_cutoff_1300_hard_20000000`，期間 2026-05-21 至
2026-08-19，共 63 個交易日。

![2,000萬 normal carry：獲利、現貨新單額與隔夜留倉](assets/normal_20m_carry_backtest_20260821.png)

圖中獲利是 terminal date 才認列的 realized cashflow，沒有把尚未平倉部位每日 MTM，
因此累積線不是完整的逐日 equity curve。底圖紫色柱使用
`overnight_carried_out_one_way_notional_twd`：普通日是 13:20 study-cutoff 的模型快照，
到期日再扣除官方 Close 釋放。它是回測實際傳給下一個 session 的帳面部位，但不是行情
已重播至 13:30 後所觀測的真正收盤庫存；在 13:00 後無新倉的設定下，可把它視為實際
13:30 留倉的保守上界。

## 模型隔夜部位與跨日連續性

| 指標 | 結果 |
|---|---:|
| 13:20、到期Close調整後的模型carry日均 | 11.160M |
| P50 / P90 | 11.812M / 18.877M |
| 最大值 | 19.950M |
| 模擬帳務的相鄰交易日庫存銜接 | **62 / 62 完全相等** |

逐日均滿足：

`D opening carry + D accepted entries - D completed/released notional = D model carry`

且下一個交易日：

`D+1 opening carry = D model carry`

三個到期日的 13:20 部位會在官方 Close 作帳後結清，因此模型帶到下一 session 的值為
零。使用這個 after-expiry 欄位，才能使「下一天從今天模型留下的部位開始」在回測帳務
上成立。`62 / 62` 是 simulation bookkeeping continuity，不是 13:30 實盤觀測驗證。

## 估計限制

- 固定 45 檔商品是回溯 cohort，帶有使用未來區間篩選商品的 data leak，尚未換成每天
  D-1 可得的動態商品池。
- 543／1,779 筆接受部位的 terminal 使用抽樣 continuation 近似；另有 90 筆以到期
  官方 Close 作會計 mark，不等於可執行 BBO。
- PnL 已扣目前指定的現貨／期貨雙邊 commission 與稅，但未扣資金成本、保證金成本、
  最低手續費 rounding、共同市場容量／impact，也沒有 carry MTM。
- 現行行情 replay 於 13:20 結束；13:20–13:30 尚未重播，因此圖中的模型 carry 不是
  精確的 13:30 收盤留倉。由於 13:00 後不再開新倉，後十分鐘新增 normal exits 只會讓
  真正留倉更低，不會讓它高於圖中上界。
- 因此 1.411M 應視為目前最簡設計的研究估計，不是可部署收益保證。
