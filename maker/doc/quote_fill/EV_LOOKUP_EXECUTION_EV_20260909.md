# S2 第一順位、成交後 50ms 與出場 EV 的核對

本次回答兩個問題：是否應調整出場 EV，以及期貨 inside maker 為何仍出現進場收益下修。
只增加診斷，未修改交易引擎、EV 參數或重跑新的政策績效。

## 1. 出場 EV 與實際退出政策並不一致

`decide.py` 固定呼叫 `est_short(..., L=-5, slot_free=True)`。
`ev_rules.py` 的估值是：

```
P(當日退出) × (effU + 5 - 20)
+ P(非當日退出) × (ab - 34)
```

第二項相當於到期 basis 歸零的 C8 分支。但 `portfolio.py` 跨日後仍會按凍結的
`anchor - 5bp` 目標退出，不是所有非當日部位都持到到期。
一般隔夜目標退出在理想目標價格下應是 `effU + 5 - 34`，與 `ab - 34`
相差 `anchor - 5`。只有到期分支才可在 C8 假設下使用 basis 歸零的現金流。

例：ab=80bp、anchor=50bp、effU=30bp。公式的隔夜分支是 46bp，
但按現有目標在隔天平掉只有 1bp，尚未扣價格變化與資金占用。
這是估值與退出政策不一致，不是證明任何平倉都很差。

新版 EV20 的一般平倉中，有 416 筆 S1、1,326 筆 S2 是隔夜退出。
對這些固定部位，把「到期歸零」與「既定 anchor 目標退出」兩個理想公式相比，
名目加權差額共約 996,574 元。這只是分支公式差異，**不是可再從已實現損益扣除的損失，
也不是修 EV 後能多賺的金額**。

另外，`choose_L`、`should_cross` 雖然已定義，目前沒有接入 `Portfolio.second()`；
實際仍是固定 L=-5、每秒維護現貨 maker 出場，沒有依當下 EV 選擇 L 或切換 taker。

應對齊的決策契約是：

- 進場 EV 分開估計當日一般退出、隔夜一般退出、到期、未能完成必要 hedge 等分支。
  每個分支使用成交條件下的四腿現金流、稅費、持有時間及資金占用。
- 掛單時估計的價差不能直接當成成交後可鎖住的價差。對成交條件下的價格變動建表，
  區分等成交期間的漂移、成交附近的共同價格變動、hedge 延遲與五檔深度。
- 出場在相同狀態比較不同 L、繼續 maker、立即 taker、繼續 carry 的淨價值。
  最低要求是 EV 假設的退出方式與程式實際採用的方式一致。
- 各決策僅能使用當時已知行情及前日以前已完成的訓練結果；尚未結束部位不能當作已獲利樣本。
  填單機率與等待期間的委託預留也影響資金使用，不能只比較成功成交者的平均 bp。

這些是具體需要修正的模型契約；目前沒有新的完整績效，不能宣称單改公式能恢復原日均。

## 2. 原先 -8,186 元／日不是全部由 50ms 避險造成

固定原 v17 的 S2 集合，重新取期貨觸發前一個納秒的現貨 as-of 盤口，
以及觸發後 0／10／50／100ms 的現貨五檔，並與前次 50ms 核價逐筆對帳。
時序依資料的 receive timestamp，不能等同於兩交易所精確同步的撮合時鐘。
目前回放以公開期貨成交行情的接收時間作觸發基準；實盤 hedge 應從自己的成交回報可知時點計算。
兩條訊息路徑的延遲尚未校準，因此不能把本回放直接稱為實際帳戶的避險滑價分布。

在前後兩個時點都可完整核價的 2,229 筆上：

| 價格差額來源 | 整段 TWD | 除以原 85 日 |
|---|---:|---:|
| 原整秒進場價格至期貨 print 前的價格變動 | -481,446 | -5,664 |
| 期貨 print 前至 print 後 50ms 的變動 | -214,129 | -2,519 |
| 另 1 筆只有 50ms 可核價，無法拆分 | -200 | -2 |
| 前次 S2 核價差額合計 | **-695,775** | **-8,186** |

約 69% 的已量得差額在期貨 print 前已形成，約 31% 落在之後 50ms。
它們是相對舊價格的收益下修，**不是 S2 每天本身就虧 8,186 元**。
原整秒價格比 print 早約半秒（中位數約 492ms）；用較早現貨 Ask 配上稍後期貨成交，
會把成交時已經不存在的價差算成可獲利空間。

仍有 288 筆在 50ms 未能按原核價器規則定價，其中 283 筆在 print 前也未能定價，
只有 5 筆是 print 前可核價而 50ms 後不可。不能把它們都描述成「50ms 內 A1 才消失」。
未核價組包含漲停無 Ask、非正式盤口及前次已另列的 4 筆單邊 Ask 限制；沒有把它們當零損益。

前次診斷仍有錯合約、book-cross 及合約身分缺失的舊前提，因此另看較明確的
**同合約 print、前後均能核價的 1,819 筆**：

- 1,361 筆價格不變（74.8%）、429 筆變差（23.6%）、29 筆改善（1.6%）。
- 現貨可買到的完整數量價格在 50ms 內平均惡化約 3.98bp；中位數 0bp，95 分位約 24.10bp。
- 這批成交條件樣本的 50ms 淨差額為 -187,050 元。它包含盤口深度變化，並非任意時刻的市場滑價分布。

因此一般時候零滑價，與少數成交時刻造成顯著損失，可以同時成立。
但本研究的接收時序、50ms 假設與 maker 成交近似仍需與實際下單回報核對，不能把數字當實盤保證。

再固定所有延遲都能核價的**同一批 1,818 筆 v17 同合約 print**，得到：

| print 後延遲 | 平均現貨價格惡化 | 中位數 | 變差筆數 |
|---|---:|---:|---:|
| 10ms | 1.51bp | 0bp | 125（6.9%） |
| 50ms | 4.04bp | 0bp | 429（23.6%） |
| 100ms | 5.57bp | 0bp | 525（28.9%） |

這是固定成交集合的報價敏感度，不會因延遲不同就換一批比較樣本。
它尚未重放延遲改變後的委託共用深度、缺價尾部、容量及退出，不能按比例外推新策略收益。

## 3. 6488：前次 6,020 元例子並不是 50ms 內滑掉 3 元

2026-05-04、原 cid 633、OWFE6 合約：

| 事件 | 開盤後時間 | 價格／狀態 |
|---|---:|---|
| 原策略掛期貨 sell 621 | 478.000000s | 原期貨 Bid 617／Ask 622；621 前方量 0 |
| 原回測取現貨價格 | 564.000000s | 現貨 618 |
| 現貨 Ask 首次到 621 | 564.952315s | 掛價 basis 已不為正 |
| 原同合約期貨 print | 564.953072499s | 成交觸發價達 621 |
| print 後 50ms | 565.003072499s | 可買 2,000 股現貨的價格仍是 621 |

這張期貨單已等約 86.95 秒。現貨到 621 僅比期貨 print 早約 0.757ms，
即使收到這則現貨行情即撤單，在 50ms 撤單假設下也來不及阻止原成交。
這筆前次 -6,020.40 元全是 print 前價格差額，print 前至 +50ms 的新增差額為 0。
本例沒有找到更早的期貨 Bid 越過我方價；首次該類 Bid 反而晚約 42.53ms，不能說本例被 FIFO 延後填單。

## 4. 第一順位與回放模型

期交所盤中使用價格及時間優先；當掛價確實改善 Ask、委託已接受且價格仍最優，
在同一合約的賣方序列有優先權。這不代表另一個現貨市場會等期貨成交後才變價。
官方依據：[期交所撮合原則](https://www.taifex.com.tw/cht/4/oamPrinciple)。

回放的 `queue.add(o, book.ahead(side, price))` 在未被占用的 inside 價位給前方量 0，
並沒有固定把 inside S2 塞到原 Ask 隊尾。抽查新版 EV20 的 5/4、6/25、7/24 共 93 筆
已成交 S2，送單時皆滿足原 Bid < 掛價 < 原 Ask，且掛價前方量為 0。

但研究模型仍有兩個必須分開的限制：

1. 送單後持有固定價格，每秒檢查 basis、effU 地板及盤面有效性；沒有持續保證自己仍是新的
   A1-1tick，也沒有每次盤口變動都完整重算 EV。掛價失效與撤單生效之間仍可能成交，成交不能刪掉。
2. maker 填單主要由歷史公開成交量觸發，未全面重建我方 inside 報價加入後的反事實撮合。
   公開 Bid 到達我方賣價，可能是更早的可成交訊號；不能僅以「共用成交量驗證通過」宣稱是真實成交時刻。

對上述 93 筆另查「送單超過 50ms 後、原 print 前已有足量 Bid 越過我方價」，找到 8 筆。
最長提前約 169.61ms，其餘多為亞毫秒；固定那些時間再取 +50ms 現貨買價，
8 筆與原回放實際現貨進場成本都相同。本樣本沒有顯示這項限制能補回重大進場損失，
也沒有證明其他日期、未成交單與出場方向都不受影響。
