**距到期是階梯函數，不是連續的**：最後 3 天每 session 到達率翻倍、明天是結算日時 C1 跳到 .51、結算日當天 C0 最高；4 天以外全部平坦（差異在 CI 內）。
因此 k 桶定為 **`0 / 1 / 2–3 / ≥4`**（`K_EDGES = (0, 1, 3)`）：近到期三格機制不同各自保留，4 天以外合併，讓每格天數從 4–23 變成 100+。
一個月只有一次到期，所以近到期三格即使全期也只有 5–6 天，這是資料本身的上限。

bp 座標（e 直接用 bp）給出幾乎相同的 pooled 機率；e=60 bp、x=−20 bp 的 score 約 5.8 勉強過 hurdle。

讀法：
- 以 maker 實測成本，**殘差 ≤ 33 bp（e ≤ 2）沒有任何出場水位為正 EV**；殘差 50 bp（quote_ab 80）最佳是最深的 x=−1.0，4.7 bp／日仍低於 20% 年化的 hurdle。
- 這與 maker 的實現同量級：S2 每筆 16–18 bp、持有 2.8 日 ≈ 6 bp／日。也解釋了 maker 的 25 bp residual 門檻為何要靠 EV 閘再擋掉大半。
- 到期路徑在 e ≥ 1.25 就是正 EV，但 T = 10 日，score 只有 0.2–3.1；只有 anchor 本身很高（≥ 90 bp）的商品，到期列才過 hurdle（見下）。

### 本輪加的 gate 與設定值

| 設定 | 值 | 原因 |
|---|---|---|
| `K_EDGES` | (0, 1, 3) → 0 / 1 / 2–3 / ≥4 日 | 剖面在 4 日以外平坦；近到期三格機制不同 |
| `q` 分桶 | (e_b, x, k_b) → (x, k_b) → (x) | pooled q 對高水位樂觀 3–7 倍（e_b=3 的 q .10 vs pooled .29） |
| `min_days` | 5 | 天數才是有效樣本；SE 以取樣點數算會低估 5–10 倍 |
| `MAX_SCALE_BP` | 60 | 4162 這類 scale 115 bp 的商品是盤口爛，pooled 格子給它 C0=.33 沒有意義 |
| `min_anchor_bp` | 0 | 1608 anchor −71、resid +99 是除息跳空，不是可收斂的殘差（maker 同結論） |
| `d_settle` | 0 + 3 margin | 到期收盤賣現貨的滑價未量測；maker C8 實現常為負 |
| e 桶上緣 | 加 4.0 | ≥2.5 開放桶混入 100 bp+ 極端值 |

### 判讀（要老實講）

這條路在 taker 表下非常肥（平均 19 bp／日），但那是**概估**，有三個已知偏差：樣本是「第一次跨門檻」事件（尖峰型與持續型混在一起）、收斂判定是瞬間 taker 可執行（對 maker 出場成交是上界）、門檻只有四個。
maker 的實現（S2 每筆 16–18 bp、2.8 日）遠低於這個數字，所以 Stage 3 一定會看到「絕對路線預測 vs 實現」的大落差；那時用本線雙向表算出來的「進場後出場側在水位 0 首次成交」分佈換掉它。
這條路現在的價值是讓高 anchor 商品**進得了候選**，讓回測有機會校準它，而不是它的數字已經對。

程式：`ev/abs_reach.py`，`ev.evaluate_absolute`，`choose` 兩路合併；48 項測試通過；`surface --full` 印絕對表與 `route` 欄。
